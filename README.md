# Three-Stack Shuffle

Bart Massey and Claude Code

A work-in-progress study of a three-stack LIFO card-sorting
machine — a deck plus two buffers, four one-card moves — asking
how few moves it takes to sort a shuffled deck (the headline
target is 52 cards), via admissible lower-bound heuristics, exact
search, constructive merge sorters, and a companion
permutation-distance model. Results are partial and still
evolving; see `docs/OVERVIEW.md` for current details.
